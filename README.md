# Verificación de vigas · CIRSOC 201-2025

Herramienta web de apoyo para verificar vigas rectangulares de hormigón armado a flexión y corte, con la memoria de cálculo paso a paso y referencias a los artículos del reglamento.

Es un único archivo (`index.html`) sin dependencias de instalación. Los datos de la planilla se guardan en el navegador de quien la usa.

Herramienta de apoyo: no reemplaza la verificación del profesional responsable.
